## 保留的策略边界

审查者考虑以下行为后未列为问题；作者逐项核对并接受这些边界：

- 可以跟随预计会离开的敌军进入移动链。若敌军实际未离开，由引擎阻挡；代价是可能损失本轮进度。预测状态仍经过完整移动解析。
- 未缓存的临时预测坐标使用曼哈顿距离作为估计。代价是在复杂障碍图上低估路径；实际移动仍只枚举合法相邻地面。
- 旗点历史沿用 worker 固定的地图数组顺序，同时使用旗点 ID 关联旗帜。当前 worker 不重排静态数组；若将来改变该约定，应改用 ID 保存历史。
- 短期预测不模拟刷新和复活，每轮以新观测修正。代价是临近刷新或复活时的战术可能次优。
- 掉旗保护统计敌方可能造成的致命伤害，不承诺涵盖对手故意射击自己队友。此时仍可能出现动态携旗移动失效；对手行为不能由预测保证。
- 重启需重新建立缓存。算法和内存有界，最大地图真实 worker 已验收；墙钟结果只对实测机器和负载有效，故障重启不会增加引擎给定的时限。

没有遗留的审查问题或推迟处理的小问题。

审查后仅根据实测选择评价系数和各人数的预测轮数，beam 上限 20、最大后续预测 3 轮不变，未改变 FFI、几何、结算预测或文件/进程边界。最终参数的测试及实战结果见实测报告；审查不证明参数最优。

## 资源验收后的补充修复

作者后续在最大地图实测中发现首轮预计算约 79ms，通过真实 worker 重启复现第 3 回合的 50ms 超时。按需射线缓存解决密集出生场景后，分散出生场景仍暴露整图重复扫描造成的连续超时。因此将风险限制在射程覆盖区、每个预测局面只提取一次地面旗列表，保持每格的浮点累加顺序。两项性能回归先失败再通过；作者验证 22 项陪练测试、83 项完整 Rust 测试、密集/分散布局四场最大图正常调用和故障恢复，以及全部 74 场最终回放的 31649 个公开观测逐动作等价。本项属于审查后的作者验证，未声称独立审查者重新审过性能修复；保留所有失败记录和前版二进制，实际结果与交付哈希见实测报告。
