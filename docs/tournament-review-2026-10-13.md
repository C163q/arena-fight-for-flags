# 自动测评机独立审查与修复

审查范围 `70f8908..6fd6a19`，独立审查一次，无二次审查。审查者检查赛程、输入冻结、执行恢复、统计及报告，并实跑 16 个测评单测及临时进程探针。没有 Critical；一个 Important 与一个 Minor。以下两项均已修复，并在修复前通过测试复现。

## 强制终止后仍有活跃 runner

原执行器把 runner 放进独立 session，但未关联测评父进程死亡，输出锁只由父进程持有。SIGKILL 测评机后 runner 继续工作、锁已释放，续跑可能重复同场并导致两份完成结果。已有 worker 父进程清理只响应 runner 死亡，无法弥补这一层。

修复在独立 Python 启动助手中设置 Linux `PR_SET_PDEATHSIG=SIGKILL`，检查父 PID 启动竞态后 exec 裁判；不使用 Python `preexec_fn`。锁描述符通过 `pass_fds` 继承到实际执行/验证进程，父进程仅关闭自己的描述符，不显式解开共享锁，确保子进程仍存活时不能开始另一场。

回归 `test_sigkill_cannot_leave_runner_live_with_unlocked_output` 在旧实现复现“runner 存活但输出已解锁”，修复后通过。真实脚本 `tests/tournament_parent_cleanup.py` 又强制终止运行中的测评机，确认 runner 与 worker 停止、锁覆盖子进程存活期，再续跑两个完整比赛，回放均验证成功；本地数据为 `runs/tournament-v1/sigkill/`。

## 显示名 Markdown 转义

审查者标为 Minor；执行者按输出正确性要求处理：显示名允许任意字符串，原始名称中的图片、链接、强调、代码和实体不应变成报告指令。原转义遗漏这些字符，阅读报告时会展示不同内容。

修复先转义 HTML 实体，再转义 Markdown 标点。`test_display_names_remain_plain_text_in_markdown` 修复前失败、修复后通过；CSV 仍保存原始显示名，不添加 Markdown 转义。无遗留的小问题。
