# Fight for Flags 首个可运行版本实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付可运行的 Rust 夺旗裁判、公开 C ABI、独立 AI worker、基准 AI、逐轮记录及离线 HTML 回放工具。

**Architecture:** 纯规则引擎拥有全部权威状态。runner 串行启动/恢复每队 worker，通过有界消息交换局面与动作，统一结算后落盘。Python 导出器只消费结构化记录生成离线 HTML。

**Tech Stack:** Rust 2024、Cargo workspace、serde/serde_json、ron、libloading、libc；Python 标准库和原生 HTML/JS。首版 Linux 64 位。

**Spec:** [规则](../../rules.md)、[架构](../../architecture.md)、[API](../../api.md)、[回放](../../replay.md)、[地图](../../maps.md)、[基准 AI](../../benchmark-ai.md)。用户已接受剩余默认方案；终局阈值来自地图 RON，由本项目设置逐图默认值。

## Global Constraints

- 每队 3 棋子、2–8 队；血量 3、命中伤害 1、无自然回血。
- 曼哈顿射程 5，直线仅命中指定格，友伤开启，自射非法，途中棋子不挡弹、不受伤。
- 串行调用每队 AI，每队 50ms；所有队伍基于同一开始快照，先射击后移动。
- 携旗不能射击、不能移入地上旗格；死亡原格掉旗，完整缺席随后十轮，第 t+11 轮开始复活。
- 开局 `max(1,(N+1)/3)` 个旗点立即生成；后续到期在移动后生成，未携旗占格即时携旗，携旗占格失败重新等待 5–15 回合。
- 每旗点最多一面未消失关联旗；仅交回得分使旗消失并安排下一面旗，旗不自动过期。
- 记录 JSON 与 ASCII/TXT 从同一帧数据生成；重放采用实际动作与故障降级，不重新执行 AI。
- 原有七张地图保持为可运行的候选测试场；公平性改良不伪装成已经完成的竞技平衡。

## Review Focus

- 极端非法坐标/动作、坏 ABI 与超长协议消息不能导致裁判崩溃或无界分配（任务 1、3、4）。
- AI 在初始化、调用、退出阶段失控或在返回后继续后台计算时，不得拖住比赛或继续争抢下一队 CPU（任务 4）。
- 射击后新掉旗、已有地上旗拾取、生成失败重试必须按实际阶段处理，保持来源旗唯一（任务 2）。
- 回放中断、缺帧、目录逃逸、特殊 AI 名称及 HTML script 闭合文本须正确诊断/转义（任务 5）。
- 相同种子与实际动作重放应得到一致状态；不同队伍调用先后不泄露已提交动作（任务 2、4、5）。
