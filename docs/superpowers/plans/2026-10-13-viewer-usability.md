验证重点：拖入 manifest 等错误 JSON、错误嵌套状态、两次异步加载先后颠倒、播放中更换比赛、跨回合保留视野、满血隐藏/受伤显示、视口高度和窄屏横向溢出。

验证中旧 CLI 集成测试出现一次父死亡检查时序失败，单独重跑通过。它以 /proc 看到两个子进程为就绪条件，固定等待 50ms，未保证子进程已完成启动。改为最多 1 秒轮询 waitpid 等待实际退出，与独立后代清理检查的等待策略一致，永久残留仍使测试失败；不修改 worker 行为或 AI 的 50ms 决策预算。

验证记录：新单 JSON 导出测试先失败后通过；旧八队页面在 1440×900 下超过视口的浏览器检查先失败后通过。新页面覆盖 1440×900、1366×768 与 390×844，验证缩放/平移/适配/全屏、回合切换保留视野、受伤血条、数据选择/拖放、坏版本/嵌套字段、错误恢复、播放中换比赛、最后一次异步选择生效、名称转义和原有播放控件。41 项 Rust 测试、8 项 Python 测试、fmt/clippy 及独立暂停/活动后代清理检查通过。原比赛重新导出的示例保存在 `runs/viewer-v2/{2p,8p}/`，无需重新比赛。
