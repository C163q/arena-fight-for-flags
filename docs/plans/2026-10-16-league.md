# 多 AI、多地图测评实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans 在当前会话逐项实施，最后一次独立审查。

**Goal:** 自动补位、精确两两均衡组合与换位、跨地图等权测评。

**Architecture:** 新 league CLI 与三个独立 Python 模块负责赛程、计划和统计；沿用原执行器，loader 兼容两版计划。Rust 裁判增加无 AI 的地图校验查询。

**Tech Stack:** Rust、Python 3.10+ 标准库；不增加运行依赖。

**Spec:** [已确认设计](../design/specs/2026-10-16-league-design.md)

## Global Constraints

- 不改游戏规则、ABI、正式地图；首回合 250ms、后续 50ms。
- 正式 jobs=1；所有在途子进程清理、并发来源保留、原始记录验证沿用。
- 每块精确候选/位置/候选对/有序位置对均衡；不完整块不得排名。
- 新配置及计划 version=2；旧版 version=1 兼容；新工具不加入题包。
- 默认 repeats=1、计划 10000 场上限，可显式提高；不静默截断。

## Review Focus

- 多地图中一张较快完成：仅完整全图重复序号入总榜，测试缺图组过滤。
- 候选在很多场缺席：统计只按实际出场分母，测试不同容量及填充排除。
- 紧凑构造非标准人数：1–16 × 2–8 全量计数验证，不以种子代替均衡。
- 计划生成时地图被替换：校验冻结副本且锁定程序与输入指纹，测试变更拒绝。
- 旧题包只含旧自测模块：loader 保持 version=1 独立可用，题包单测及仓库外验收。
