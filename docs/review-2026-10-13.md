## 实现取舍与审查边界

- 目标分和最大回合只由地图 RON 提供；改变此决定需修改地图/CLI 契约。
- 公共策略工具独立成 ai-sdk，仅依赖 ABI；若取消此边界，成本为合并一个小 crate。
- 默认 AI seed 与引擎独立，显式策略种子另传；调整需变更 CLI 政策和元数据。
- 地图位置差异、基准策略强度和恶意代码沙箱是已记录限制；扩展分别需要平衡评估、策略改良或 OS 沙箱项目。
- 主动更改进程组/凭据、访问其他进程不属于可信本地 AI 契约；普通 fork 的清理已修。需要覆盖前者时必须增加 OS 隔离。
- 任意手工 Rust from_snapshot 或极端 line_cells 参数无生产 CLI 输入路径；若作为不可信外部 API 开放，应追加防御校验和测试。
- 截止检查的极短窗口、暂停确认竞态和内核不可中断 I/O 未取得可控失败证据；不承诺硬实时，进一步保证需要专用调度/OS 约束。
- 并发换文件、FIFO 等特殊文件与断电目录耐久性不在普通完整前缀恢复范围；覆盖这些情况需文件类型/no-follow/目录同步设计。
