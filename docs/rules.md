# 游戏规则草案

状态：用户要求已整理；补充规则为待确认提案。“已明确要求”及明确标注为已确认的条目是已知约束，其余提案用于讨论，关联 [决策清单](decisions.md)。

## 已明确要求

- 每队固定三个棋子，每回合每棋子只能移动一格、射击一次或等待；移动仅上下左右，射击目标曼哈顿距离 ≤5，必须校验合法性，非法射击不执行。
- 棋子血量为 3，不随回合恢复；每发命中扣 1。子弹沿直线飞向指定格，只有指定格可能受伤，途中棋子不受伤也不阻挡子弹。障碍仍阻挡子弹。
- 存在友伤，合法命中其他友方棋子也扣 1；射击目标等于射手自身坐标时非法，不执行。这里“自身坐标”指提交射击操作的棋子所在格，不是任意棋子所在格。
- AI 能看到全图及所有棋子的坐标、血量、携旗状态。
- 回放记录射击者、目标坐标、射击结果、血量及携旗状态/变化，既方便 LLM 阅读，也可转换成人类播放器。
- 地图覆盖 2–8 人，运行时读取加载；边界全部封闭。当前按每人一队设计，采用 RON 格式。
- AI 根据局面一次提交整队动作，计算不能超过 50ms；超时终止计算，当前回合整队原地不动。
- 各队 AI 串行调用，基于同一回合开始快照决策，排队等待其他队伍的时间不计入本队预算；所有提交收齐后统一结算。
- 主程序先执行所有射击，再执行所有移动。
- 棋盘包含不可进入且阻挡子弹的障碍、随机时间刷新旗帜的旗点，以及每队一个 3×3 出生区。
- 初始三个棋子随机出现在己方出生区。携旗棋子不能射击；带旗回到己方出生区后旗消失，解除携旗并加 1 分。
- 携旗者死亡时旗帜掉落在死亡格。携旗者移动到有地上旗帜的格子属于非法操作，不移动。
- 每个旗点只有在其上次生成的旗帜消失后，才开始随机等待重刷；当前唯一的消失方式是交回己方出生区得分。旗帜不自动过期，拾取、携带或掉落均不触发重刷。
- 旗帜重刷延迟暂定 5–15 回合，后续可调整；两端均包含，默认采用整数均匀随机。
- 开局随机选择约三分之一旗点立即生成旗帜，数量为 `K=max(1,(N+1)/3)`，整数除法，即四舍五入且至少一个；其余旗点等待 5–15 回合首次生成。
- 正式回合的旗帜生成发生在所有棋子移动之后；未携旗者占据到期旗点时生成成功并立即携旗，携旗者占据时生成失败，从当前回合重新随机等待 5–15 回合。
- 第 t 回合死亡的棋子完整缺席 t+1 至 t+10 回合，t+11 回合开始时在己方出生区复活；第 5 回合死亡即完整缺席 6–15 回合，第 16 回合开始复活。
- 同时争抢同一目标格时都不移动。例如 `(0,0) -> (0,1)` 与 `(0,2) -> (0,1)` 均失败。
- 相邻交换时，友军交换成功、敌军均不移动。例如 `(0,0) <-> (0,1)`。

待确认参数可以在正式规则冻结前调整。地图、回合/分数上限和刷新延迟建议作为显式比赛配置；血量 3、命中伤害 1、曼哈顿射程 5、无自然回血是固定规则，配置不能覆盖。所有 AI 通过 API 获得这些规则常量和本场参数。

人数范围、每队三棋子、3×3 出生区和封闭边界是明确约束。地图是独立 RON 文件，尺寸从文件读取；具体 schema、七张地图索引及校验见 [地图设计](maps.md)。

每个棋子有稳定 `(team_id, unit_id)`，`unit_id` 为 0、1、2；死亡与复活不会换 ID。死亡棋子仍存在于结构化状态，但没有棋盘坐标，不占格。

## 回合阶段

初始状态编号 `0`，记录随机出生后的棋盘，不允许 AI 对初始状态直接执行半回合动作。正式动作回合为 `1..max_turns`。

| 阶段 | 行为 |
| --- | --- |
| 1. 开始 | 处理到期复活，生成各队本回合观测；此时不生成到期旗帜 |
| 2. 收集 | 串行调用各队 AI，全部使用同一开始快照；收齐整队动作，超时/故障应用整队等待；动态移动校验在射击后进行 |
| 3. 射击 | 依据同一个射击前快照计算所有弹道与累计伤害，然后同时扣血、处理死亡及掉旗 |
| 4. 移动 | 只为射击后仍存活的棋子处理移动意图，统一解决争抢、阻塞和环 |
| 5. 旗帜 | 按提案先拾取已有地上旗，再按移动后棋盘尝试到期生成/失败重试，生成在未携旗者脚下时立即携旗，最后处理得分 |
| 6. 结束 | 记录完整回合结果，检查分数与回合上限 |

回放记录开始阶段复活和移动后生成的不同阶段。AI 决策时看不到本回合稍后才生成的旗；这些结果进入结束状态及下一回合观测。t=0 的开局立即生成属于比赛初始化，不等待一次不存在的移动阶段。

## 动作校验

三种动作互斥：`Wait`、`Move(direction)`、`Shoot(x,y)`。死亡棋子的槽位也必须存在，动作被规范化为等待。

移动越界或进入障碍、携旗者移动到有地上旗帜的格子、携旗射击、射击目标越界/曼哈顿距离超 5/等于射手自身坐标、未知动作/方向等，视为对应棋子等待，并记录原因，非法射击不产生子弹或伤害。射击目标格被其他友方或敌方棋子占据，不构成非法条件。允许瞄准障碍格/空格仍为提案；空格只会落空，障碍遮挡只会阻止命中。行动结束后不能再换动作，例如射击前携旗，即使本回合后来掉旗也不能补射。

与动态棋盘相关的移动合法性在射击结束、死亡掉旗之后检查。目标格只要有至少一面地上旗帜，携旗者就不能进入；即使其他棋子计划本回合拾走该旗，也不重新判定为合法。此意图在争抢与依赖图计算前剔除，不能作为有效争抢者阻止未携旗棋子进入该格。

范围检查必须在读取目标格前进行，坐标差用足够宽的整数计算，避免恶意极值溢出。被墙阻挡的合法射击与超射程的非法射击是不同结果，回放分别记录。

协议无法解释、缺少棋子槽位、请求 ID/版本不符等属于整队提交失败，由 runner 降级为整队等待，不交由引擎猜测含义。

## 已确认的射击、血量与观测

射程只按曼哈顿距离判断：射手 `(sx,sy)`、目标 `(tx,ty)` 满足 `abs(tx-sx)+abs(ty-sy)<=5`。例如 `(0,0)` 到 `(0,5)` 或 `(3,2)` 的距离为 5，到 `(3,3)` 的距离为 6，后者不能射击。这里只演示距离，实际还需校验目标在地图内等条件。

弹道是一条通往指定格的直线，**不是沿曼哈顿路径拐弯飞行**。伤害仅在目标格判定，途经格的棋子不会受伤，也不会阻挡子弹，无论它属于哪一队；不超出目标格继续飞行。障碍会阻挡命中。目标无存活棋子时，不对附近或之后的棋子造成伤害。D06b 已确认，不能将途中棋子作为遮挡物。

棋子最大血量为 3，每发有效命中造成 1 点伤害，血量不随回合恢复。AI 可见整个地图以及所有棋子的坐标、血量与携旗状态。死亡棋子没有当前坐标，API 用显式存活状态表示，不能伪造仍在棋盘上的位置。

D06c 已确认存在友伤：若指定格内是另一名友军，且其余射击条件合法、路径未被障碍遮挡，就造成 1 点伤害，与命中敌军相同。射击自身格则在合法性检查中直接拒绝，即使距离为 0、满足射程上限也不能执行；合法射击的距离因此为 `1..=5`。射击先于移动，使用射击阶段开始时射手和目标的位置。

## 仍需确认的射击补充

- D06a：建议从格中心到格中心使用整数 supercover 轨迹检查障碍；擦到障碍边/角也阻挡。它只用于遮挡检查，不能使途中棋子受伤。
- D06d 补充：建议允许瞄准空格或障碍格；瞄准不等于命中。拒绝自身格射击已经确认。
- D05 补充：建议无弹药限制和额外射击冷却；用户确认的无自然回血不等于确认了这些资源规则。

同时结算的具体提案：所有射击使用射击前同一状态计算目标命中，累计伤害后一次扣血。因此两个符合条件的射手可以同归于尽，本阶段被击杀的射手仍完成已提交射击；死亡棋子的移动取消。若多发命中同一棋子，记录各发来源与总伤害，结算血量为 `max(0, old_hp-total_damage)`。

每回合每棋子只有一个操作，不能移动中射击；每队最多三次射击。

## 移动提案（D10）

使用射击后状态，不允许多个棋子占同一格。等待、射击和非法移动者均视为保持原位。

1. 过滤越界、障碍、已死亡，以及携旗者目标格有地上旗帜的非法移动意图。旗帜状态使用射击及死亡掉旗后的快照。
2. 对同一目标格有两个或更多有效意图的，全部取消；不会挑一名赢家，也不会在后续重新开放竞逐。
3. 剩余移动形成依赖图：目标格有棋子时，当前移动依赖该棋子成功离开。
4. 通向空格的链全部成功；通向不离开的棋子的链全部失败，阻塞向前传播。
5. 闭环全部属于同一队伍时同时成功；闭环包含不同队伍时全部失败。
6. 一次应用所有成功移动，不逐棋子修改棋盘。

| 示例 | 结果 |
| --- | --- |
| A 与 B 均移入同一空格 | 两者均停留 |
| A 进入 B 原格，B 等待 | A 停留 |
| A 进入 B 原格，B 进入空格 | A、B 均成功；链不要求同队 |
| A、B 相邻互换，属于同队 | 两者成功（用户明确要求） |
| A、B 相邻互换，属于敌队 | 两者失败（用户明确要求） |
| 同队四名或更多棋子形成环 | 首版每队三棋子无法构造此例；通用算法按同队环处理 |
| 两队四棋子绕 2×2 成环 | 全部失败（补充提案） |
| A 移入射击阶段刚刚死亡的 B 原格，B 未携旗 | 该格现为空格，按正常规则处理 |
| A 已携旗，移入刚死亡的携旗者 B 原格 | B 掉旗后该格有地上旗，A 移动非法、原地不动 |
| A 未携旗，移入刚死亡的携旗者 B 原格 | 掉旗不使 A 的移动非法；仍检查争抢与依赖，成功后可拾旗 |
| A 已携旗、B 未携旗，均尝试进入同一有旗格 | 先取消 A 的非法移动；B 不因 A 的无效意图构成同格争抢 |
| A、B 争抢一格，B 后续因其他依赖也会失败 | A 仍失败，不重新争抢 |

正交网格没有长度为三的环，同队三棋子在首版实际只会形成两两互换；一般闭环规则用于完整描述与未来扩展。

## 已确认的掉旗与携旗移动限制（D07）

携旗棋子死亡时，旗帜立即掉落在其死亡格，解除该棋子的携旗状态；旗帜不随棋子消失，也不立刻返回来源旗点。射击先于移动，因此同回合的移动合法性检查必须看到这些新掉落的旗帜。

携旗者不能移动到任何有地上旗帜的格子，判为非法并保持原位；旗帜来源、数量及是否刚掉落不影响该限制。空旗点没有地上旗，不因其旗点标记而禁止携旗者进入。被其他棋子携带的旗不算地上旗，该棋子的占格仍按一般移动规则处理。

生成发生在移动之后；移动合法性不会被本回合稍后生成的旗倒过来改变。携旗者若移动到一个没有地上旗、但将在本回合尝试生成的旗点，移动可按一般规则成功；之后该棋子阻止生成，旗点重新随机等待。射击死亡掉旗发生在移动之前，仍会影响携旗者的移动合法性。

## 已确认的旗帜生命周期与重刷（D08）

旗点是地图静态地形，旗帜是独立动态物品。每面旗有稳定 ID 和来源旗点；状态为地上、被携带或已消失。每旗点最多一面尚未消失的关联旗，无论它是否还在旗点上。

旗帜被捡走后，来源旗点虽然看起来为空，仍关联同一面存活旗帜，不能开始重刷。携带者死亡只将这面旗转为死亡格上的地上旗，不取消来源关系、不重新抽取刷新时间，也不会自动让旗消失。

当前唯一的旗帜消失方式是携旗者将其交回己方出生区，解除携旗并为该队加 1 分。只有此时来源旗点才开始随机等待下一面旗；地上旗帜和被携带的旗都没有自动过期时间。下一面旗仍生成在原来源旗点，不在上一次死亡格生成。

重刷延迟当前默认 5–15 回合，包含 5 和 15，默认均匀抽取整数 d。等待范围是可调比赛配置：`flag_respawn_min_turns=5`、`flag_respawn_max_turns=15`，要求 `1<=min<=max`；一次比赛使用启动时的配置，后续平衡调整作用于新比赛。每场回放保存实际范围、分布与抽取结果，不把范围写死在 ABI 或 AI 策略中。

计时边界：第 t 回合交回消失后抽取 d，第 `t+d` 回合所有棋子移动后尝试生成。例如第 20 回合交回、抽到 5，第 25 回合移动后尝试生成；第 25 回合 AI 的开始观测尚不包含这次新旗。引擎不得在此前的拾取或死亡掉落时提前抽样或开始计时。

## 开局首次生成（已确认）

在初始状态 t=0 创建时，从全体 N 个旗点中随机选取 `K=max(1,(N+1)/3)` 个，使用整数除法，立即在这些旗点生成旗帜，写入初始棋盘。选择使用引擎显式种子，在稳定旗点 ID 列表上无放回抽样；同一旗点不能重复选取。

其余未选中旗点分别抽取首次延迟 d，当前为闭区间 5–15 内的整数均匀随机，于第 d 回合移动后首次尝试生成，失败按相同占格规则重新等待。首次生成独立于交回流程，不需要一面不存在的旧旗先消失；一旦生成，该旗遵守相同的携带、掉落、交回消失和重刷规则。

数量按上述公式四舍五入且至少一个。N=1、2、3、4 时选 1 个，N=5、6、7 时选 2 个，N=8、9 时选 3 个；始终满足 `1<=K<=N`。

未来实际刷新回合建议属于引擎内部信息，不传给 AI；AI 可看到当前已生成旗帜及已公开的延迟范围。

## 到期生成与占格重试

首次延迟、交回后的延迟和生成失败后的重试都在对应回合所有移动结束后处理。检查当时实际位置及携旗状态，不能沿用 AI 开始观测中的占格。移动前占据旗点、之后离开的棋子不再阻止生成；移动后到达的携旗者会阻止生成。

空旗点到期正常生成。携旗者占据旗点时不生成任何新旗，不改变已有携旗、不产生拾旗或得分；在失败回合 t 重新抽取 d，下一次尝试安排在 t+d 的移动后阶段，不是每回合持续重试。失败重试不需要上一面旗再消失一次，因为这次尝试尚未创建旗帜。

未携旗者占据旗点时生成成功，并在同一个生成阶段立即携带新旗，不等待下一回合。记录生成与携旗变化两个关联事件，来源旗点仍关联这面新旗，不开始再次重刷。

| 生成阶段旗点状态 | 结果 |
| --- | --- |
| 无棋子 | 生成地上旗 |
| 有存活且未携旗的棋子 | 生成成功，棋子立即携旗 |
| 有已携旗的棋子 | 生成失败，不创建旗，重新随机等待 5–15 回合 |

占格判断使用当前携旗状态。按已有旗拾取先于到期生成的阶段提案，若未携旗者先拾到该格其他地上旗，本次生成时已携旗，按失败重试处理。

## 旗帜补充提案（D07 补充）

- 未携旗棋子在旗帜阶段自动拾取脚下的旗，一次最多一面；若同格有多面掉落旗，按旗 ID 升序取第一面。
- 携旗者不能射击、不能移入有地上旗帜的格子，其他移动/等待按一般规则；每个棋子最多携带一面旗。拿旗只改变后续回合可用动作。
- 射击阶段掉落的旗可在同回合移动后被存活且未携旗的棋子拾取；自动拾取阶段仍为补充提案。
- 地上旗帜不自动过期已确认；建议不阻挡子弹，允许未携旗者进入，但禁止携旗者移入。
- 旗帜阶段，携旗棋子只要位于己方出生区，即得 1 分并使该旗消失；包括本阶段刚在出生区拾到掉落旗的情况。

## 死亡、出生与复活（边界已确认，补充见 D09、D11）

死亡以射击累计伤害后血量 ≤0 为准，立即移除占格，保留棋子 ID 和计时信息。D09 的时间边界已确认：第 t 回合死亡，完整缺席 t+1 至 t+10，t+11 开始时处理复活。第 5 回合死亡的棋子不参与第 6–15 回合，第 16 回合开始复活后可以参与该回合决策与行动。

出生与复活的补充提案：只从己方 3×3 出生区的空闲可行走格中随机选择，不能与任何队伍棋子重叠；复活满血、无旗。多个到期者按稳定棋子 ID 依次分配空格。无空格时继续保持死亡状态，下一回合重试，并记录阻塞事件。无空格例外仍待确认，不能把已确认的十轮缺席边界重新列为未决。

出生区没有无敌、回血或禁止敌军进入的效果。其全部格子必须可行走，各队出生区不相交。

## 终局提案（D02）

全回合所有队伍结算结束后再检查目标分数。若至少一队达到目标分，或者已到回合上限，则按最终分数比较；唯一最高分者胜，最高分并列则整场平局，并列队伍单独列出。多队同时达到目标不能按棋子或队伍遍历顺序先判胜。
