# 游戏规则 v1

本文是首版玩法单一来源。用户已接受补充默认方案，确认记录见 [设计决策](decisions.md)；程序实现和测试以本规则为准。地图布局是可运行测试场，竞技公平性仍需改良。

## 棋盘、单位与信息

- 2–8 队，每队固定三个棋子；每队一个独立 3×3 出生区。
- RON 在运行时加载，最外圈全部封墙。障碍不能进入且挡弹；各出生区和全部旗点通过正交地面连通。
- 坐标 `(x,y)` 左上原点，x 向右、y 向下；上下左右分别 `(0,-1)/(0,1)/(-1,0)/(1,0)`。
- 每棋子稳定 ID 为 `(team_id,unit_id)`，unit_id=0、1、2；死亡复活不换 ID，一格最多一棋子。
- 初始三棋子在己方出生区随机无重叠出现，满血 3、无旗。敌军可进入出生区，没有无敌或额外回血。
- AI 全图可见，知道所有棋子的坐标、血量、携旗、死亡/复活信息，以及当前旗、比分和规则参数；不知道未来实际刷新时刻、引擎 RNG 或其他队伍本轮动作。

每个棋子每轮唯一操作：Wait、上下左右移动一格、射击指定格。AI 一次提交整队三个动作，每队完整调用 50ms，超时终止并本轮整队 Wait。不同队伍串行调用，基于同一开始快照，排队时间不扣本队预算。

## 比赛参数

目标分与最大回合数来自地图 `match_limits.target_score/max_turns`，必须为正整数，max_turns 上限 1000000；CLI 不覆盖。七图当前默认为：

| 人数 | 尺寸 | 目标分 | 最大回合 |
| --- | --- | --- | --- |
| 2 | 25×25 | 5 | 500 |
| 3–4 | 29×29 | 6 | 650 |
| 5 | 33×33 | 8 | 800 |
| 6–7 | 37×37 | 10 | 1000 |
| 8 | 41×41 | 12 | 1200 |

旗帜生成等待范围默认 5–15，闭区间整数均匀抽取，允许按比赛配置调整；要求 `1<=min<=max<=1000000`。本场启动后固定，写入回放。血量 3、伤害 1、曼哈顿射程 5、无自然回血是固定规则。

## 初始状态与回合顺序

t=0 是随机出生和开局旗布局后的初始状态，不执行动作。N 个旗点中无放回随机选 `K=max(1,(N+1)/3)` 个立即有旗，`/` 为整数除法；例如 1–4 点选 1 个、5–7 点选 2 个、8–9 点选 3 个。其他旗点各抽等待 d，在第 d 回合移动后首次尝试生成。

| 阶段 | 行为 |
| --- | --- |
| 1. 开始 | 处理到期复活；构建供全部 AI 决策的同一快照，不生成到期旗 |
| 2. 收集 | 串行调用各队 AI，收齐全部操作；协议失败/超时整队 Wait |
| 3. 射击 | 同一射击前状态判定全部射击，累计扣血，再处理死亡和原格掉旗 |
| 4. 移动 | 用射击后状态校验意图，统一处理争抢、依赖和环，应用成功移动 |
| 5a. 拾取 | 未携旗者拾取脚下已有地上旗，同格多旗按 ID 升序取一面 |
| 5b. 生成 | 按移动后的占格及当前携旗状态处理到期旗；未携旗占格即时携旗，携旗占格失败重试 |
| 5c. 得分 | 携旗者位于己方出生区时交旗、加分、使旗消失，安排来源旗点下一次等待 |
| 6. 结束 | 保存完整结果，再判断终局 |

t=0 立即生成属于初始化，不等待一次不存在的移动阶段。正式回合刚生成的旗不在该轮开始观测中，只进入结束状态和下一轮输入。

## 校验与失败

未知动作、非法方向、移动越界/进入墙、携旗者移入地上旗格、携旗射击、射击越界/超范围/自身格等，只有对应棋子改为 Wait，并记录原因。正常结果中的单个非法游戏动作不使整队失败。

外层 ABI 版本/大小/槽位错误、AI 返回失败、worker 崩溃/超时等，忽略整份输出，整队 Wait。截止前仅写出部分结果也不采用。初始化/重启另限 1000ms、退出限 100ms；故障重启丢失私有 context。

死亡棋子不占格；对开始时已死亡棋子提交非 Wait 不产生行动。射击期间刚死亡的棋子原本合法移动被取消，记 `killed_before_move`，保留其原始起点/目标，不算提交非法动作。

## 射击与血量

目标曼哈顿距离满足 `1<=abs(tx-sx)+abs(ty-sy)<=5`；目标必须在图内且不是射手本身。距离计算使用宽整数避免极值溢出。可以瞄准空格或障碍格，分别落空或被障碍挡住。

子弹从射手格中心沿直线到指定格中心，不沿曼哈顿折线飞行、不越过目标继续飞行；只检查目标格的存活棋子是否受伤。途中棋子不挡弹、不受伤，旗帜也不挡弹。

障碍遮挡采用整数 supercover：直线接触障碍边/角也阻挡。起点不作为遮挡；目标障碍格也阻挡。路径上的障碍优先使射击无伤，目标友军与敌军均可受伤。

具体例子：障碍在 `(0,0)`，A 在 `(0,1)`，B 在 `(1,0)`，两格中心连线接触障碍的角，因此双方均不能命中对方；再增加 `(1,1)` 障碍仍然阻挡。这里坐标用于解释局部几何，实际地图外圈必须封墙。等价的内部平移布局已覆盖单障碍、双障碍及双向射击测试；移除两侧障碍后可以互相命中。

每发命中扣 1，生命初始/复活为 3，不随回合恢复；无弹药限制和额外冷却。全部射击使用同一快照，先统计命中来源再一次累计扣血，血量下限 0。被本阶段击杀的射手仍完成已提交射击，所以可以同归于尽。死亡者不再移动，携带旗立即掉在死亡格。

## 同时移动

先过滤越界/墙/死亡等无效意图；携旗者目标格有任意地上旗时也非法，使用射击及死亡掉旗后的快照，包含本轮新掉旗。随后：

1. 两个或更多有效意图指向同格，全部失败，不选赢家，也不在后续重新争抢。
2. 剩余意图指向有棋子格时，依赖该棋子成功离开。
3. 通向空格的链全部成功；通向不移动棋子的链全部失败，阻塞传播。
4. 同队闭环同时成功，混队闭环全部失败；特别是友军相邻互换成功、敌军互换失败。
5. 最后一次应用所有成功位置，不逐棋子抢先修改状态。

若携旗者 A 和未携旗者 B 都尝试进入有旗格，先取消 A 的非法意图，B 不因 A 构成争抢。携旗者不能因另一棋子计划稍后拾走该旗而解除本轮禁入。空旗点可进入；其他棋子携带的旗不算地上旗，仍按一般占格规则结算。

## 旗的生命周期与生成

每旗有稳定 ID 和来源旗点，每个来源最多一面未消失的旗。被拾走、携带、掉落都保持该来源关系，不启动下一面旗的等待。旗没有自动过期，只能交回己方出生区得分后消失。

未携旗者移动后自动拾取一面旗，携旗者最多一面，不能射击。射击阶段掉落的旗可在同轮移动后接力拾取。若脚下有多面不同来源的旗，按 ID 最小者拾取，其他留在地上；旗不阻挡未携旗者移动。

第 t 回合交旗消失后抽取 d，第 t+d 回合所有移动结束后尝试生成；例如 t=20、d=5，在第 25 回合移动后尝试。旗仍在外面时，即使来源格空着，也不会重刷。

| 尝试时旗点状态 | 处理 |
| --- | --- |
| 无棋子 | 生成地上旗 |
| 未携旗的存活棋子 | 生成成功，该棋子立即携旗 |
| 已携旗的棋子 | 不生成，从失败回合重新抽 5–15 回合等待 |

失败不创建旗，不伪造旧旗消失；第 t 回合失败、抽 d，则下次在 t+d 移动后尝试，首次生成失败同样重试。用实际移动后位置和拾取后的携旗状态判断：占格者离开不阻碍生成，携旗者新到达会阻碍。新生成旗不会反向使已经完成的移动非法；射击掉旗则发生在移动前，仍会使携旗移入非法。

得分阶段，携旗者只要位于己方出生区即加 1 并交回；包括刚在出生区拾到掉落旗。新等待的来源点是该旗最初生成点，不是死亡格。

## 复活与终局

第 t 回合死亡，完整缺席 t+1 至 t+10，第 t+11 回合开始复活并可参与本轮行动。例如第 5 回合死亡，6–15 完整缺席，第 16 回合开始复活。满血、无旗，保留 ID。

按稳定棋子 ID 依次从己方出生区空闲格随机选择，不能与任何队伍重叠。出生区全满则继续死亡、下一回合重试，记录 respawn_blocked。

所有队伍完整结算后，若至少一队达到地图目标分，或回合数达到地图上限，则唯一最高分者胜；最高分并列为平局，列出全部并列队伍。不能按队伍/棋子遍历顺序提前判胜。
