## 后续优先事项

1. 改善地图公平性：地图 v3 将各槽最近旗点距离增加至 6–8 步并完成 20 分标定，但全基准自战仍有位置偏好。对每次布局调整重测全出生槽，不沿用旧评估结论。
2. 丰富公开参考 AI：护送/拦截分工、风险模型、多回合搜索及记忆；继续走同一 ABI 和决策预算（首回合 250ms，之后 50ms）。
3. 扩展随机和手工规则局面，补充更多跨阶段组合；格式或规则变更同步版本与重放兼容策略。
4. 超长回放按需加载、更多射击/移动动画和队伍筛选；当前单 HTML 导出有明确大小上限。
5. 若将来执行不受信任的恶意二进制，独立设计 OS 沙箱与文件/网络/进程权限策略。当前 worker 隔离只保证常规超时和崩溃处理。

在线匹配、账号系统、GPU 训练、分布式裁判和随机地图生成不属于当前首版；新增时单独设计，不在本次交付中声称已经支持。
