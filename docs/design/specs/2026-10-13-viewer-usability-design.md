# 回放播放器改进

用户授权自行选择播放器方案。采用通用离线页面 `viewer/index.html`：将比赛目录导出成一个 `replay.json`，通过选择文件或拖放载入；保留把同样数据嵌入 HTML 的导出方式。两种方式共用同一页面代码，旧比赛目录可重新导出，无需重新比赛。不直接让浏览器读取整个比赛目录，减少文件选择兼容性与部署要求。

桌面页面使用固定视口布局，棋盘为主要区域，比分紧凑排列，详细信息在侧栏的事件/棋子/AI 标签中独立滚动。窄屏改为上下排列，棋盘仍有明确高度。存活棋子只有受伤时显示头顶三格血条；满血隐藏，携旗仍显示，完整状态保留在详情中。

棋盘支持缩放按钮、鼠标滚轮缩放、指针拖拽平移、适配窗口与全屏；切换回合保留视野，加载另一比赛重置。移动端提供按钮缩放和单指拖拽。鼠标悬停或点击棋子查看位置、血量、携旗/复活信息。

文件加载前检查大小、版本、地图、帧序列及页面消费的状态/事件结构。失败显示可读错误并保留已有比赛；异步加载只采用最后一次选择。全部运行在本地浏览器，无网络请求。浏览器校验是结构校验，完整规则仍由 Rust verify 负责。

擦角规则保持：两格中心的闭线段只要接触任何障碍格的闭边界即挡弹。障碍 (0,0)、A (0,1)、B (1,0) 不能互射，增加障碍 (1,1) 仍不能；测试使用等价的地图内部平移坐标。

验收：真实八队回放在常用桌面视口不产生纵向页面滚动；加载、替换、错误恢复、血条、缩放/拖动/重置、全屏、原播放控件和窄屏操作通过 Chromium 检查。
