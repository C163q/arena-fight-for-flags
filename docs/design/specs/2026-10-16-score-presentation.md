# 千分制评测显示

用户已确认：主积分采用 0–1000 千分制。此改动只改变显示尺度，不改变单场比较、地图权重、完整块要求、并列与排序规则。

- Markdown 主积分、出生位名次积分和 95% 区间显示为整数，正数四舍五入（半分向上）；例如 0.5005 → 501。
- JSON/CSV 保留原有 0–1 `rank_score` 及 JSON 的 `rank_score_ci95`，新增整数 `score` 和 JSON 的 `score_ci95`；JSON 顶层 `score_scale=1000`。league 的 `by_map` 保留原值，新增 `by_map_score`。出生位条目新增 `score`。
- 排名继续使用现有未取整值和精确分数比较；显示积分相同不自动并列。平均夺旗分、独胜率和其他原始统计不乘 1000。
- 同步固定名单 tournament 与 league、参赛自测模板及使用文档。不修改 ABI、worker、执行器、计划格式或题包白名单。
- 现有 1010 场报告通过读取原始记录重建，不重跑正式比赛。旧题包不原地改写，生成新的 release 题包并做独立验收。
