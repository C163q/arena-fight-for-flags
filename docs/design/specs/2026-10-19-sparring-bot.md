# 陪练 AI

目标：提供一个尽力争胜、可复用的 Rust 陪练库，强度通过实战描述，不承诺战胜所有未知策略。独立于现有基准，不改游戏、接口或题包白名单。

## 方案

纯最短路策略计算便宜，但容易在交战中损失旗帜；完整多队博弈搜索分支过大。采用地图缓存、联合任务分配与有界战术搜索：缓存正交距离和擦角挡弹射线；根据公开旗帜变化估计等待，为三个棋子联合分配任务；枚举合法移动/等待/敌人格射击，协调集火并预测短期交战。借鉴既有提交的联合集火和预测思路，重新实现 Rust 版本。

预测只是一种策略假设：敌人可能采取任何动作，不读取实际敌方动作、引擎 RNG、未来刷新或比赛文件。死亡后的掉旗先于移动，模拟友军换位、移动链、混队环和同格冲突。携旗者通过带风险代价的路径返家。

新增 `bots/sparring`，仅生产依赖 `fff-ai-abi`。地图、预测、任务和动作搜索分别独立成模块；context 保存地图缓存、旗点历史和上轮位置，重启可从观测恢复。地图最大 128×128，距离按目标懒计算且限制缓存容量；不分配最大地图的平方矩阵。搜索分支和预测深度设固定上限。

## 交付与验证

构建产物 `target/release/libfff_bot_sparring.so`。新增策略使用说明和实测报告，README/文档导航同步。源代码和有意义的规则边界测试入 Git，二进制、版本快照、对局及分析放在忽略的 `target/`、`runs/`。

先做几何、移动及死亡掉旗测试，再做集火/取旗/返家案例；真实 worker 预检，2–8 队换位、自战、对基准及历史强提交实战。开发可并行但标记为自测；最终计时与验证采用串行。调参种子与留出种子分开。报告样本、胜负/积分、故障、非法动作及调用分位耗时，未知对手强度仍不确定。
