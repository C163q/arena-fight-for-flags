# 查看比赛回放

回放可以帮助你定位具体问题：某个棋子为什么没移动、谁向哪个格子射击、何时受伤、何时拾旗或交旗。先找到一场比赛的记录文件夹，再导出供浏览器观看的文件。

## 找到一场比赛

如果使用 `fff-runner --out runs/my-match` 直接运行比赛，记录就在 `runs/my-match/`。

如果使用 `selftest.py run` 或 `compare`，先在测试输出目录的 `versions/` 下选择版本，再在该版本的 `matches/` 下选择场次。比赛记录位于 `attempt-*/match/`。`tournament.py` 的记录则直接放在其计划目录的 `matches/` 下。需要核对具体场次时，可查看报告旁的 `results.json`。

本页以 `runs/my-match` 为例；使用自测工具时，请把命令中的这个路径换成找到的单场记录目录。

## 导出并打开

以下命令在 `fff-contest/` 文件夹中执行：

```sh
bin/fff-runner verify runs/my-match
python3 viewer/export.py runs/my-match
```

第一条根据已记录的操作重新计算比赛，核对记录是否一致，不会重新调用 AI。第二条生成以下两个文件：

| 文件 | 如何使用 |
| --- | --- |
| `runs/my-match/replay.html` | 用浏览器直接打开，即可看这一场比赛，也便于分享 |
| `runs/my-match/replay.json` | 打开 [通用播放器](../viewer/index.html)，将此文件拖入页面，或点击“打开回放”选择它 |

两种方式都不需要网络或启动服务器。通用播放器可以反复打开不同比赛，不必每次换页面。只需要通用播放器的数据文件时，可以运行：

```sh
python3 viewer/export.py runs/my-match --format json
```

## 播放器里能看什么

可以自动播放、调整速度、前后一回合单步查看，也可以用滑块或输入回合号跳转。使用“回合开始／回合结束”选项，可以分别看 AI 决策前的局面和本回合结算后的局面。

棋盘支持缩放、拖动、适配窗口与全屏。受伤棋子上方会出现三格血条，满血时不显示。点击棋子可看详细状态；侧栏可查看比分、本回合事件、棋子状态，以及 AI 调用是否超时或失败。

## 直接阅读文本记录

每场比赛包含地图、初始状态、`frames/` 中的逐回合 JSON/TXT，以及结束摘要。JSON 适合程序读取；TXT 用字符画出棋盘，并列出棋子、比分、动作、射击结果、血量及携旗变化，适合直接阅读，也可以交给 LLM 分析。

字符棋盘的图例为：`#` 墙、`.` 地面、`0`–`7` 出生区、`o` 旗点、`*` 地上旗、`A`–`X` 棋子。棋子会覆盖同一格的地形字符，因此只看字符图可能看不出它脚下是什么，应结合明细。文本中的 `START`、`END` 分别表示回合开始、结束状态。

导出成功只表示格式可读，不能代替前面的 `verify` 完整校验。比赛尚未结束时，也可以查看已经完整写出的回合。导出器最多读取 25000 帧，单个源文件不超过 16MiB，总输入不超过 512MiB；超限会提示错误。

## 汇总与备份

如果希望先看多场比赛的统计，可运行 `selftest.py summary`。保存完整记录可用 `archive`，恢复可用 `restore`；恢复后仍需选择单场目录导出回放。这些操作不会重新运行 AI，命令见 [自测说明](testing.md)。
